# AHMETHOD — Smart Accounting & Business Management

نسخة GitHub Pages من نظام الحسابات، مع فصل HTML/CSS/JavaScript مع الحفاظ على وظائف النظام الأصلية.

## الملفات
- `index.html` — الواجهة
- `css/style.css` — التصميم
- `js/app.js` — منطق النظام

## تسجيل الدخول
- المستخدم الأساسي لإدارة النظام: `admin`
- كلمة السر الافتراضية: `admin123`

## المستخدمون والاشتراكات
- يوجد إنشاء حساب/اشتراك من شاشة الدخول.
- حساب الاشتراك الرئيسي يصبح مدير شركة (`companyAdmin`).
- مدير الشركة يستطيع إضافة مستخدمين لمؤسسته وتحديد صلاحيات العرض والإضافة والتعديل والحذف لكل قسم.
- حساب `admin` هو مدير النظام الأساسي ولا يمكن حذفه من واجهة المستخدمين.
- يتم حفظ بيانات الحسابات والاشتراكات وبيانات النظام محليًا داخل `localStorage`.

## تنبيه مهم
هذه النسخة تعمل كتطبيق ويب ثابت على GitHub Pages. لذلك الحسابات وبيانات الشركة محفوظة محليًا في المتصفح والجهاز نفسه، وليست قاعدة بيانات مشتركة بين أجهزة الموظفين. لا تعتبر بيانات الدخول المحلية نظام مصادقة خادميًا آمنًا.

للمستخدمين المشتركين عبر أجهزة متعددة أو اشتراكات مدفوعة حقيقية، يلزم ربط النظام بقاعدة بيانات وخدمة مصادقة خلفية.
